# Software FJ – Sistema Integral de Gestión de Clientes, Servicios y Reservas
Proyecto POO en Python (sin bases de datos). Ejecutar: `python main.py`

Estructura: `excepciones.py`, `logger.py`, `entidades.py`, `servicios.py`, `reserva.py`, `gestor.py`, `main.py`.
Los errores y eventos se guardan en `logs/eventos.log`.

# Software FJ - Sistema de Gestion de Clientes, Servicios y Reservas

Proyecto de Programacion Orientada a Objetos en Python (sin bases de datos).

Para ejecutarlo: `python main.py`

Archivos:
- excepciones.py: excepciones personalizadas
- logger.py: guarda eventos y errores en logs/eventos.log
- entidades.py: clase abstracta Entidad y clase Cliente
- servicios.py: clase abstracta Servicio y 3 servicios (sala, equipo, asesoria)
- reserva.py: clase Reserva
- gestor.py: guarda clientes, servicios y reservas en listas
- main.py: simulacion de 12 operaciones
